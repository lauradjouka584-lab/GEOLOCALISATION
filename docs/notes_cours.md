Technologies de Géolocalisation et Cartographie

GNSS/GPS : Le GNSS (Global Navigation Satellite System) désigne l'ensemble des systèmes de géolocalisation par satellite, dont le GPS est le réseau américain. La puce du smartphone capte les signaux satellites en temps réel pour calculer avec précision les coordonnées géographiques (latitude, longitude et altitude).

WGS 84 (World Geodetic System 1984) : Système de référence mondial offrant un repère géospatial commun pour la cartographie, la navigation et les drones. Il s'appuie sur un ellipsoïde de référence (une forme mathématique), un système de coordonnées tridimensionnel et un réseau de points de contrôle.

NMEA 0183 : Protocole de communication standardisé par la National Marine Electronics Association, conçu pour assurer l'interopérabilité des équipements issus de différents fabricants. Les données de positionnement sont transmises sous forme de phrases textuelles débutant par les caractères $ ou !.

Réseau et Échange de Données

HTTPS : Protocole de communication sécurisé permettant à l'application mobile d'interagir de manière chiffrée avec le serveur Python via Internet.

JSON : Format de données léger et universel utilisé pour structurer les informations échangées entre l'application et le serveur.

Sécurité et Authentification

Bcrypt : Algorithme de hachage utilisé pour sécuriser les mots de passe en les transformant en chaînes de caractères indéchiffrables.

JWT (JSON Web Token) : Standard utilisé pour générer un jeton d'accès sécurisé, servant à vérifier l'identité et les autorisations de l'utilisateur lors de ses requêtes.
